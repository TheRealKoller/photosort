# 0004 - KI soll die Anwendung lokal im Browser ansehen können

**Typ:** Idee
**Erfasst:** 2026-08-04
**Status:** Unrefined

## Rohtext

Die KI soll die Möglichkeit haben, die Anwendung im Browser anzusehen, wenn sie lokal läuft. Idealerweise wird die Anwendung dazu lokal gestartet (mittels docker compose) und dann kann die KI drauf zugreifen. Welche Möglichkeiten gibt es da? Ist das überhaupt eine gute Idee?
