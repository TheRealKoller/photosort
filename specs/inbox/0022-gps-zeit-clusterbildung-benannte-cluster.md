# 0022 - GPS- und zeitbasierte Clusterbildung für benannte Cluster

**Typ:** Idee
**Erfasst:** 2026-08-15
**Status:** Unrefined

## Rohtext

Falls vorhanden sollen GPS-Daten ausgewertet werden. Sie können helfen, Cluster zu bilden. Die Clusterbildung soll nach Möglichkeit den Ort und die Zeit berücksichtigen, um benannte Cluster zu bilden. Um ein Cluster zu bilden, könnten die folgenden Merkmale verwendet werden: Zeitfenster, GPS-Koordinaten und erkannte Sehenswürdigkeiten. Wenn beispielsweise klar ist, dass einige Bilder zeitlich zusammengehören und einige Bilder dieses Clusters GPS-Koordinaten haben, kann man davon ausgehen, dass auch die anderen Bilder in diesem Zeitfenster an der Stelle gemacht wurden. Andersherum kann es aber auch sein, dass Bilder, die zeitlich anscheinend zusammenpassen, tatsächlich zwei Cluster sein sollten, die nur sehr kurz aufeinander folgen. Auch hier könnten GPS-Koordinaten helfen. Erkannte Sehenswürdigkeiten können auf die gleiche Art helfen.
