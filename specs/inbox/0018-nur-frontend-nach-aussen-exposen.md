# 0018 - Nur Frontend nach außen exposen

**Typ:** Idee
**Erfasst:** 2026-08-14
**Status:** Unrefined

## Rohtext

Kann man die Anwendung so ändern, dass das Backend nicht nach außen exposed sein muss? Aktuell muss ich sowohl das Frontend als auch das Backend nach außen geben über den Reverse Proxy. Es wäre schöner, wenn ich nur einen Port und eine URL exposen müsste.
