# 0014 - test-engineer überarbeiten, kompakter arbeiten lassen

**Typ:** Idee
**Erfasst:** 2026-08-07
**Status:** Unrefined

## Rohtext

Der test-engineer könnte vielleicht etwas überarbeitet werden. Er braucht nicht zu prüfen, ob TDD verwendet wurde, wenn ein Review gemacht wird. Insgesamt sollte er vielleicht etwas kompakter arbeiten, vielleicht so, dass er sinnvoll mit einem günstigeren Modell laufen kann.
