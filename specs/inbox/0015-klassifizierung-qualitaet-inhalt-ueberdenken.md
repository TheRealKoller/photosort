# 0015 - Klassifizierung: Qualität und Bildinhalt überdenken

**Typ:** Idee
**Erfasst:** 2026-08-09
**Status:** Unrefined

## Rohtext

Die Klassifizierung der Bilder muss nochmal überdacht werden. Welche Möglichkeiten gibt es, um die Qualität von Bildern zu bestimmen? Welche Möglichkeiten gibt es, um Bildinhalte zu bestimmen (Mensch, Tier, Landschaft, Gebäude, Sehenswürdigkeit, etc.)? Vielleicht kann man KI-Modelle auf die Bilder anwenden (z.B. Anthropic, Mistral, oder Modelle auf Replicate oder Huggingface)? Bei der Verwendung von KI-Modellen muss eine Kostenkontrolle eingebaut werden. Teilweise werden Ordner mit tausenden Bildern bearbeitet, das würde unter Umständen tausende KI-Anfragen bedeuten. Das muss unter Kontrolle gehalten werden. Letztendlich sollte jedes Bild Informationen zu seiner Qualität und seinem Inhalt haben. Über diese Informationen kann dann abgeleitet werden, welche Kategorien es in diesem Ordner überhaupt gibt, welches die jeweils besten Fotos jeder Kategorie sind, und letztendlich was die besten Fotos insgesamt sind.
