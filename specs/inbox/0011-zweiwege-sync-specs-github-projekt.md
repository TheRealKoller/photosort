# 0011 - Zweiwege-Synchronisation Specs ↔ GitHub-Projekt

**Typ:** Idee
**Erfasst:** 2026-08-09
**Status:** Unrefined

## Rohtext

Eine Synchronisation der Specs im Repository und Issues in einem GitHub-Projekt. Vielleicht ein Zwei-Wege-Sync. Aktualisierungen in Issues im GH-Projekt werden in die Spec-Files übernommen, und der aktuelle Zustand der Spec-Files wird im Projekt-Board abgebildet. Dazu könnte z.B. ein Skill erstellt werden (nochmal prüfen), der requirements-engineer könnte sich darum kümmern. Wenn Änderungen aus GH übernommen werden, muss auch geprüft werden, ob ein (erneutes) Refinement notwendig ist.
