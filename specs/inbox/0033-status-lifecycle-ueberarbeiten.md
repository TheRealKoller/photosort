# 0033 - Status-Lifecycle für Feature-Specs/Inbox überarbeiten

**Typ:** Idee
**Erfasst:** 2026-08-23
**Status:** Unrefined

## Rohtext

Feature/Spec-Workflow überarbeiten. Eine Idee oder ein Bug sollen zuerst als Unrefined erfasst werden. Wenn sie refined sind (durch den idea-sharpener), sollen sie als Ready markiert sein. Jetzt sollten sie eine Priorität haben. Wenn sie implementiert wurden, sind sie Implemented und damit fertig. Ein Ticket durchläuft den ganzen Zyklus, außer es gibt Gründe, es vorzeitig zu schließen — dann wandert es in Closed.
