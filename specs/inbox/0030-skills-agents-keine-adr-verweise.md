# 0030 - Skills und Agents sollten keine ADR-Verweise oder ähnliches enthalten

**Typ:** Idee
**Erfasst:** 2026-08-21
**Status:** Unrefined

## Rohtext

Skills und Agents sollten keinen Verweis auf ADRs oder ähnliches haben. Im Skill/Agent muss nicht stehen, wie es dazu gekommen ist — die Skills und Agents sollten ohne Bezug auf ADRs funktionieren. Generell sollten nur andere Files referenziert werden, wenn sie für den Skill/Agent für die Funktion von Bedeutung sind. Es ist ok, sich auf eine Datei zu beziehen, die bestimmte Kommandos enthält, oder auf eine Datei, die der Skill pflegen soll etc. Aber keine Files, die nicht direkt mit dem Skill zu tun haben.
