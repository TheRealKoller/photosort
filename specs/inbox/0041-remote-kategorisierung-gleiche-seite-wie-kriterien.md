# 0041 - Remote-Kategorisierung auf gleicher Seite wie Kriterien-Bewertung

**Typ:** Idee
**Erfasst:** 2026-08-24
**Status:** Unrefined

## Rohtext

Remote-Kategorisierung sollte auf der gleichen Seite sein wie Kriterien-Bewertung, weil die Ergebnisse der Remote-Kategorisierung erst durch die Kriterien-Bewertung eingearbeitet werden.
